Hey, I'm Aryan

I'm a BCA student at RV University in Bengaluru, and most of what I make sits somewhere between software, design and AI. I like building things that actually work and feel good to use, which is why UI/UX is my minor. When I'm not coding I'm usually taking photos or editing them.

I'm looking for internships where I can build real things and learn fast.

Lately
Building Cairn, an open-source gateway that sits between coding agents and LLM providers. It estimates what a project will cost from a PRD, keeps token spend inside a budget, and can roll back what an agent changed using Git snapshots. (TypeScript, SQLite, WebRTC)
Wrapped up a four-week XR internship with Fusion VR in Chennai this summer, working on a project called Sphere Blitz.
Shipped Synapse, my most recent project, which is live online.
Things I've built

SpecAR: an Android AR app where you drop in a CSV of furniture dimensions and it places a 1:1 scale 3D model on your actual floor. You can drag it around and rotate it in 15° steps. There's a standalone APK too. React Native ViroReact ARCore

Loom: a Chrome extension that quietly turns your browsing into a knowledge graph. It picks out concepts and claims from pages you spend time on and links related ideas across pages. Everything stays on your device. React D3 IndexedDB

R2I (Route-to-Impact): an eco-routing prototype for Bengaluru that compares the fastest route against one that also weighs emissions, congestion and risk. I framed the route choice as a QUBO and solved it with simulated annealing. Python Streamlit OpenStreetMap

And more: BrandOS, CineMatch, InternetMapper, Nexum, NuxAI, SkillSwap, archscope, plus a fashion website, all in my Side-Projects repo.

Design work

Design isn't a side note for me. Some of my coursework case studies:

Campus Eats: a canteen ordering system, taken from empathy research and card sorting through information architecture to a Figma prototype.
DigiLocker UX evaluation: heuristic and task-based evaluations, plus a competitive analysis against UMANG, the Aadhaar app and ABC/APAAR.
igrsup.gov.in redesign: a heuristic-driven redesign of the Uttar Pradesh Stamp and Registration Department website.
